Mapping Delhi's shared e-rickshaw network

Delhi's metro is world-class, but many trips end at a station exit with no bus in sight. That last stretch is run by shared e-rickshaws on informal routes that no map shows.

This map shows how well buses actually serve each metro station, measured from one hour of live GPS from ~6,000 Delhi buses.
